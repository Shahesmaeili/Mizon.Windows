# Welcome typography and profile entrance

- Owner: Codex.
- Scope: Welcome text and Home header layout during the existing connected animation.

Welcome binds the headings, status, action labels and language tooltip to
the current locale font. The two actions keep their localized automation names
and existing keyboard/controller invocation.

Home reserves the native right caption inset using the window scale before
its first layout. The title-bar layout pass waits for its measured width and
stable profile bounds before starting the existing connected animation.
A short fallback shows the avatar if the bounds do not settle. Unloading
stops the fallback timer and releases any pending animation.

Validation: Debug x64 build and the existing MCP access suite. Live font
rendering, the visual transition, and hardware controller input were not
automated.
